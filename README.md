# 🏆 Sporture
**Bringing People Together Through Local Sports Events**

Sporture is a full-stack MERN web application built to connect individuals through nearby sports activities. Users can easily explore, create, and join sports events based on their interests and location — making it simple to stay active, social, and engaged.

---

## 🚀 Features

### 🧑‍💻 Authentication
- Secure **Login** and **Signup** using JWT.
- Smooth and intuitive registration flow for new users.
- Strong form validation with error prompts and loading indicators.

### 🏠 Interactive Dashboard
- Personalized **Dashboard** enhanced with smooth animations and a vibrant gradient UI.
- Displays user metrics such as:
  - Events joined  
  - Events hosted  
  - Skill level  
  - Average rating  
- Quick-access sections for:
  - Event discovery  
  - Event creation  
  - Reminders  
  - Profile settings  
  - Feedback & Ratings  

### 🏟️ Event Management
- **Create Events:** Configure sport type, venue, date/time, title, and participant limit.
- **Event Details Page:** Well-designed and animated pages showing complete event data.
- **Popular Venues:** Highlights top event locations from aggregated statistics.
- **Safe Joining:** Capacity is enforced atomically, so an event can never be overbooked by simultaneous joins.

### 💬 Feedback & Ratings
- Users can submit feedback and rate hosts/events to maintain a positive community.
- Feedback is attributed to the authenticated user and can only be deleted by its author.

### 🧭 Additional Highlights
- Fully responsive layout for all devices.
- Google Fonts + custom animated gradient design.
- Reminders page listing your upcoming joined and hosted events.
- Smooth routing with React Router.
